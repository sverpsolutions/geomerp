API Documentation for Integration: Products & Suppliers

This documentation provides details for integrating external software with the Head Office (HO) backend for Product and Supplier entities. The API uses standard HTTP methods (GET, POST, PUT, DELETE) and JSON formatting.

[!NOTE] All endpoints are prefixed with the base API URL (e.g., https://api.modernbazaarho.local/api/v1). Authentication is required for most endpoints, typically via a Bearer token in the Authorization header.

1. Product API Endpoints

The Product API allows you to manage product information, barcodes, and outlet-specific pricing.

Core Product Management

  • List Products

    • Endpoint: GET /products
    • Description: Retrieves a paginated list of products.
    • Query Parameters:
      • page (int, default: 1): Page number.
      • per_page (int, default: 50): Number of items per page.
      • search (string): Search by name, item code, or barcode.
      • category_id, brand_id, classification_id (int): Filter by specific IDs.
      • is_active, is_expired, is_hidden_pos, low_stock (boolean): Additional filters.
      • status (string): Status filter.

  • Create Product

    • Endpoint: POST /products
    • Description: Creates a new product.
    • Body: JSON object containing product details (name, item_code, category_id, brand_id, etc.).

  • Get Product Details

    • Endpoint: GET /products/{product_id}
    • Description: Retrieves detailed information for a specific product.

  • Update Product

    • Endpoint: PUT /products/{product_id}
    • Description: Updates an existing product.
    • Body: JSON object containing the fields to update.

  • Delete/Deactivate Product

    • Endpoint: DELETE /products/{product_id}
    • Description: Deactivates a product (soft delete).

Search and Barcode Lookup

  • Fast Search (QuickScan / Autocomplete)

    • Endpoint: GET /products/search
    • Description: Optimized search for POS or autocomplete fields.
    • Query Parameters: q (search string), limit (int, default: 20).

  • Lookup by Barcode

    • Endpoint: GET /products/lookup/barcode/{code}
    • Description: Finds a product exactly matching the given barcode or item code.

  • Get Product Barcodes

    • Endpoint: GET /products/{product_id}/barcodes
    • Description: Lists all barcodes associated with a product.

  • Generate/Add Barcode

    • Endpoint: POST /products/barcode/generate
    • Description: Adds a new barcode to a product or generates an EAN13 barcode.
    • Body: { "product_id": int, "barcode": string (optional), "barcode_type": string, "is_primary": boolean }

  • Delete Barcode

    • Endpoint: DELETE /products/barcode/{barcode_id}
    • Description: Removes a barcode (primary barcodes cannot be deleted without setting a new primary first).

Pricing & Activity

  • Get Outlet Pricing

    • Endpoint: GET /products/{product_id}/outlet-pricing
    • Description: Retrieves the pricing configured for this product across all active outlets.

  • Update Outlet Pricing

    • Endpoint: POST /products/{product_id}/outlet-pricing
    • Description: Updates pricing for specific outlets.
    • Body: Array of pricing objects [{"outlet_id": int, "cost_price": float, "selling_price": float, ...}]

  • Get Product Activity

    • Endpoint: GET /products/{product_id}/activity
    • Description: Returns the stock and sales/purchase activity for the last 7 days.

2. Supplier API Endpoints

The Supplier API handles vendor master data, onboarding, approvals, terms, and financial ledgers.

Core Supplier Management

  • List Suppliers

    • Endpoint: GET /suppliers
    • Description: Retrieves a paginated list of suppliers.
    • Query Parameters:
      • page, per_page
      • search (string): Search by name, phone, GST, or code.
      • registration_status (string, default: "approved")
      • pending_review (boolean): If true, returns suppliers awaiting approval.

  • Create Supplier

    • Endpoint: POST /suppliers
    • Description: Directly creates a new supplier (Admin/Manager role).
    • Body: JSON object including basic info, addresses, contacts, legal, financial, brands, etc.

  • Get Supplier Details

    • Endpoint: GET /suppliers/{supplier_id}
    • Description: Retrieves full details, including nested relationships (contacts, addresses, etc.).

  • Update Supplier

    • Endpoint: PUT /suppliers/{supplier_id}
    • Description: Updates supplier information and nested entities.

  • Delete/Deactivate Supplier

    • Endpoint: DELETE /suppliers/{supplier_id}
    • Description: Deactivates a supplier.

Vendor Onboarding & Registration (External Access)

  • Generate Onboarding Link

    • Endpoint: POST /suppliers/onboarding/link
    • Description: Generates a unique token for a vendor to self-register.
    • Query Parameters: phone (string), name (string).

  • Get Public Registration

    • Endpoint: GET /suppliers/public/registration/{token}
    • Description: Retrieves pending registration details via the public token.

  • Submit Public Registration

    • Endpoint: POST /suppliers/public/registration/{token}
    • Description: Vendor submits their registration details. Changes status to submitted.

Approvals Workflow

  • Approve Supplier

    • Endpoint: POST /suppliers/{supplier_id}/approve
    • Description: Approves a pending vendor. Assigns a unique Supplier Code.

  • Reject Supplier

    • Endpoint: POST /suppliers/{supplier_id}/reject
    • Description: Rejects a vendor registration.
    • Body: { "remarks": "Reason for rejection" }

  • Hold Supplier

    • Endpoint: POST /suppliers/{supplier_id}/hold
    • Description: Places a vendor registration on hold.

  • Request Correction

    • Endpoint: POST /suppliers/{supplier_id}/request-correction
    • Description: Requests the vendor to correct specific fields.

  • Get Approval Logs

    • Endpoint: GET /suppliers/{supplier_id}/approval-logs
    • Description: Lists the history of approval actions.

Financials & Operations

  • Get Supplier Ledger

    • Endpoint: GET /suppliers/{supplier_id}/ledger
    • Description: Returns the financial ledger (opening balance, purchases, payments).

  • Get/Add/Delete Terms

    • Endpoints:
      • GET /suppliers/{supplier_id}/terms
      • POST /suppliers/{supplier_id}/terms
      • DELETE /suppliers/{supplier_id}/terms/{term_id}

  • List/Create Challans

    • Endpoints:
      • GET /suppliers/{supplier_id}/challans
      • POST /suppliers/{supplier_id}/challans

  • Add Internal Note

    • Endpoint: POST /suppliers/{supplier_id}/notes
    • Description: Adds an internal note to the supplier's profile.
