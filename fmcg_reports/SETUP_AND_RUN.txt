# FMCG REPORTING TOOL - SETUP & RUN GUIDE
# Database: RetailWizard (SQL Server) | Backend: Python Flask
# ================================================================

## STEP 1 — INSTALL PYTHON
Download Python 3.11+ from https://python.org
During install: CHECK "Add Python to PATH"

## STEP 2 — INSTALL ODBC DRIVER FOR SQL SERVER
Download: https://learn.microsoft.com/en-us/sql/connect/odbc/download-odbc-driver-for-sql-server
Install: "ODBC Driver 17 for SQL Server"

## STEP 3 — INSTALL PYTHON PACKAGES
Open Command Prompt in the fmcg_reports folder and run:

    pip install flask pyodbc pandas openpyxl reportlab

## STEP 4 — RUN SQL VIEWS ON YOUR SQL SERVER
Open SQL Server Management Studio (SSMS)
Connect to:  157.20.172.168\SQLEXPRESS,1433
Database:    RWMBSERVER
Open file:   sql/01_create_views.sql
Click:       Execute (F5)

This will create 16 reporting views in your database.

## STEP 5 — UPDATE DB CONNECTION (if needed)
Edit app.py lines 15-19:
    DB_SERVER   = r'157.20.172.168\SQLEXPRESS,1433'
    DB_NAME     = 'RWMBSERVER'
    DB_USER     = 'sa'
    DB_PASSWORD = 'YOUR_DB_PASSWORD'

## STEP 6 — RUN THE APP
In Command Prompt:
    cd fmcg_reports
    python app.py

## STEP 7 — OPEN IN BROWSER
Go to:  http://localhost:5000
